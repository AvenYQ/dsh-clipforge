# 抖音无水印下载（给 bot 的实现说明）

纯 HTTP 五步，不需要登录、不需要浏览器、不用 yt-dlp。实测 3 秒内解析、10 秒内下完一条 5 分钟视频。

现成脚本：`scripts/douyin.mjs`，用法 `node scripts/douyin.mjs "<分享文案或链接>" [输出目录]`，输出 mp4 + 同名 json。

## 第 1 步：从分享文案里取出链接

抖音分享出来的是一段话，例如：
`4.33 复制打开抖音，看看【某某的作品】… https://v.douyin.com/xxxx/ 02/08 UYz:/ O@K.wF :6pm`

正则取第一个 URL：`/https?:\/\/[^\s，。、；;）)】"'<>]+/i`

## 第 2 步：展开短链，取出 video id

GET 短链，跟随跳转（`redirect: follow`），**必须带移动端 UA**，否则桌面 UA 会拿到 302 空页面。

移动 UA：
```
Mozilla/5.0 (iPhone; CPU iPhone OS 17_0 like Mac OS X) AppleWebKit/605.1.15 (KHTML, like Gecko) Version/17.0 Mobile/15E148 Safari/604.1
```

最终地址形如 `https://www.douyin.com/video/7701996593474608243`，用 `/\/video\/(\d+)/` 取 id。

## 第 3 步：拿到 ttwid

**这一步是整个方法的关键。** 没有 ttwid，分享页不会返回视频信息（之前所有失败都是缺它）。

```
POST https://ttwid.bytedance.com/ttwid/union/register/
Content-Type: application/json

{"region":"cn","aid":1768,"needFid":false,"service":"www.ixigua.com",
 "migrate_info":{"ticket":"","source":"node"},"cbUrlProtocol":"https","union":true}
```

从响应头 `Set-Cookie` 里取 `ttwid=...` 的值，缓存起来复用（约几天有效）。请求里如果用 `fetch`，要用 `response.headers.getSetCookie()` 拿完整 header，`get('set-cookie')` 可能只拿到第一条。

## 第 4 步：请求分享页，解析出播放地址

```
GET https://www.iesdouyin.com/share/video/<video_id>
User-Agent: <移动 UA>
Cookie: ttwid=<上一步的值>
Referer: https://www.douyin.com/
```

页面里有一段 `window._ROUTER_DATA = {...}</script>`，用正则抠出 JSON：

```
/window\._ROUTER_DATA\s*=\s*(\{.*?\})<\/script>/s
```

在 `loaderData` 里遍历所有 key，找带 `videoInfoRes.item_list` 的那一页（key 形如 `video_(id)/page`），取 `item_list[0]`。

- 标题：`item.desc`
- 时长：`item.video.duration`（毫秒，除以 1000）
- 封面：`item.video.cover.url_list[0]`
- 播放地址：`item.video.play_addr.url_list[0]`

## 第 5 步：把带水印地址换成无水印，然后下载

`play_addr` 给的是 `.../playwm/?video_id=...`，把路径里的 `playwm` 换成 `play` 就是无水印地址，其他参数一个都不要动（都是签名）。

curl 下载，同样要带移动 UA 和 Referer：

```
curl -A "<移动 UA>" -e https://www.douyin.com/ -L --fail -o out.mp4 "<play 地址>"
```

## 失败与边界

- **分享页解析不到 `videoInfoRes`**：ttwid 失效。重新申请一次 ttwid 再试；仍失败说明接口又变了。
- **`bit_rate` 是空数组**：这是分享页的正常返回，拿不到多档画质，只有 `play_addr` 这一路。
- **地址有时效**：`play` 地址带签名，过期后重新走一遍第 4 步即可，不要缓存它。
- **不要用 `ratio=1080p` 之类去改参数**：实测改动无效，返回的还是同一路流。
- **不要用 yt-dlp**：它会报 `Fresh cookies (not necessarily logged in) are needed`，因为它的抖音提取器要的是另一套 cookie，补 ttwid 也没用。
- **不要开浏览器嗅探**：能拿到但每次要 10 秒以上、还会弹窗，体积也大，只作为最后兜底。

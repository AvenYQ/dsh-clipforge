# DSH 工作台 · 前端产品需求文档（v2 重构）

> 范围：视频工作台为主，文稿台为次。目标是把现在“能跑但粗糙”的面板，重构成一个可以每天用的桌面工具。
> 文档状态：待确认。确认后按 P0 → P1 分期实施。

---

## 一、产品定位

**一句话**：把一条视频链接，在同一个面板里拆成可发布的碎片——下载、文案、片段、GIF、拼接，全程不离开工作台。

**它不是什么**：不是剪映（不做时间轴特效、转场、调色），不是下载器（不是批量爬站），不是笔记软件。

**核心矛盾**：现在功能都在，但面板把「工具」当成了「一堆卡片」——每个功能一张卡、编号各说各话、状态散落各处，用户要自己记住“我现在走到第几步”。重构要解决的是**流程可见性**和**状态可信赖**。

---

## 二、目标用户

| 用户 | 特征 | 他要什么 | 他现在怎么凑合 |
|---|---|---|---|
| **A. 内容二创者（主）** | 做短视频/图文二创，一天处理 3–10 条素材 | 快速切出高光片段、做封面 GIF、拼接多条 | 下载器 + 剪映 + 在线 GIF 压缩，三个工具来回倒 |
| **B. 研究/学习者（次）** | 看长访谈、课程、发布会 | 拿文案、要时间戳、要双语、要大纲 | 手动听写 / 第三方转写网站（上传隐私顾虑） |
| **C. 素材归档者（长尾）** | 收藏党，存了不看 | 下载后归类、可检索 | 文件夹裸放，找不到 |

**关键约束（从真实反馈来）**：
- 用户是设计师出身，**对视觉粗糙零容忍**；功能齐全但观感像“20 年前的工具”会被直接判死。
- 用户会连续操作 20–60 分钟，**状态必须可恢复**（切走再回来还在、重启后还在）。
- 用户会贴错链接、贴到需要登录的页面，**失败要能自救**，不能只给一行红字。

## 三、核心使用场景

### S1 一条视频 → 一个可发布的 GIF（最高频）
贴链接 → 解析（标题/时长/清晰度）→ 下载 720p → 拖时间轴选 3 秒 → 目标 ≤5MB → 生成 → 保存到桌面。
**关键点**：从贴链接到拿到 GIF，**不超过 5 次点击**；中间任何一步不需要切换应用。

### S2 一条视频 → 一段可发布的 mp4
同上，但在输出区选「截取 mp4」而不是 GIF；可能连续切 3–5 段（连点「加入队列」→ 一次导出）。

### S3 长视频 → 文案（含翻译）
下载 → 提取文案（字幕优先，无字幕走本地 whisper）→ 逐句中英对照 → 复制/存 .txt。

### S4 多段拼接
选 A 段 → 加入 → 选 C 段 → 加入 → 拼接导出（扔掉中间废话）。

### S5 失败自救
- 链接需要登录 → 用内置浏览器打开，登录一次，之后自动抓取；
- 站点不支持 → 明确说明，并给出「改用文稿模式」的入口；
- 下载中断 → 保留 .part，可续传，不重下。

### S6 回看历史
三天前下过的视频，今天要重新切一段：**不该重新下载**。历史里能直接唤起任务。

## 四、页面列表

```
工作台（唯一主面板）
├── 顶部：模式切换（视频 / 文稿）  工具链状态  清空
├── 视频台
│   ├── 左栏：① 输入与解析   ② 下载  ③ 文案
│   └── 右栏：④ 预览与范围   ⑤ 输出（mp4 / GIF）
│             ⑥ 多段拼接
├── 文稿台（P2，暂缓）
│   ├── 左栏：① 输入   ② 原文
│   └── 右栏：③ 产物（摘编/大纲/金句/概念/问题/双语）
└── 抽屉层：任务历史（P1）· 设置（P1）
```

**硬性约束**：两个工作台**必须共用同一个 ① 输入卡**，编号从 ① 连续到最后一格；不允许出现“从 ② 开始”的孤立页面。切换模式只换“后续步骤”，不换“第一步”。

## 五、模块结构

### 5.1 顶部工具条（`WorkbenchHeader`）
- 品牌块：图标 + 标题 + 当前任务标题（过长省略）
- 状态区：工具链健康点（yt-dlp / ffmpeg / whisper，缺失显示黄色感叹号，点开看安装指引）
- 动作区：`在 Finder 中显示`、`清空工作台`（两步确认）、构建标记（开发期可见）

### 5.2 ① 输入与解析（`InputCard`）
- 单行输入（视频模式）/ 多行（文稿模式），回车即解析
- 模式标签：`识别为：视频 / 文稿`，可手动强切
- 解析结果：封面、标题、时长、平台、作者、清晰度清单、字幕有无
- 失败态：错误说明 + 自救入口（登录抓取 / 改用文稿 / 重试）

### 5.3 ② 下载（`DownloadCard`）
- 清晰度下拉（最佳 / 1080 / 720 / 480 / 仅音频）
- 主按钮 `下载`，下载中变为进度条 + 速度 + ETA + `取消`
- 完成后显示文件名、大小、`在 Finder 中显示`

### 5.4 ③ 文案（`TranscriptCard`）
- 动作：`提取文案` / `重新提取` / `翻译`
- 视图：`双语 | 纯文本` + 时间戳开关（独立叠加，非并列页签）
- 逐句块：时间码 + 说话人 + 原文 + 译文
- 底部：`复制` / `存成 .txt` / 来源标注（字幕 / 本地转写 / 描述）

### 5.5 ④ 预览与范围（`PlayerCard`）
- 播放器（原生控件，支持全屏）
- 双把手时间轴：左把手=开头、右把手=结尾、**中间橙色区可整段拖动**
- 吸附开关（关键帧 / 句末）
- 微调 `±0.5s`、`复位`、`试播选中段`、`循环`
- 读数：剪掉片头 x 秒 / 片尾 y 秒 / 成片 z 秒

### 5.6 ⑤ 输出（`OutputCard`）
- 共用当前选区，两行互不耦合：
  - 第一行：`切法（快速/精确）` + `截取 mp4`
  - 第二行：`GIF 目标大小` + `帧率` + `宽度` + `生成 GIF`
- 产物列表：文件名、时长、大小、`保存` / `在 Finder 中显示`

### 5.7 ⑥ 多段拼接（`MergeCard`）
- 队列：`加入当前区间` → 列表（可删、可清空）→ `拼接导出 (n)`
- 结果列表同 ⑤

### 5.8 抽屉：任务历史（P1）
- 列表：缩略图 + 标题 + 时长 + 大小 + 时间 + 产物数量
- 操作：继续编辑 / 在 Finder 中显示 / 删除
- 空态引导「贴一条链接开始」

## 六、视觉风格

**关键词**：`暖色工具感` · `低饱和中性底` · `暖橙强调` · `清晰分区` · `可扫读` · `克制阴影` · `等宽数字` · `微动效`

**原则**
1. **一屏一个焦点**：同一时刻只有一个主按钮是暖橙实心，其余都是幽灵按钮。
2. **卡片不是装饰**：卡片只用来划分“步骤”，不用来装“信息块”；步骤色块（①②③）是唯一的编号系统。
3. **数字对齐**：所有时间码、文件大小、百分比用等宽数字（`tabular-nums`），右对齐。
4. **层级靠留白，不靠边框**：分区用 12–16px 间距 + 一层浅底，边框只用在输入框和分隔线。
5. **动效克制**：150–200ms，只做透明度/位移，不做弹跳；进度条允许流动条纹。
6. **深色必须可用**：所有颜色走主题 token，禁止硬编码背景色（当前 GIF 卡片有硬编码橙色底，需清理）。

**禁用**
- 圆角混用（统一 10 / 14 两档）
- 超过两级的阴影
- 图标风格混搭（现在是圆角描边 + 实心混排，需统一为一套 1.4px 描边）

## 七、关键交互

| 场景 | 交互 |
|---|---|
| 解析 | 回车即触发；输入框右侧按钮在输入为空时禁用 |
| 下载 | 单任务；重复点击同链接复用已有任务（不重复下载） |
| 时间轴 | 拖把手改起止；拖中段整段平移；点轨道移动播放头；吸附阈值 0.65s |
| 键盘 | `空格` 播放/暂停、`I` / `O` 打点、`←/→` 微调 0.1s（`Shift` 1s）、`[` `]` 调音量 |
| 试播 | 走服务端切片，播完自动停；拖选区自动退出试播 |
| 生成 | 按钮就地转为进度；>3s 显示档位（GIF）或阶段（转写） |
| 产物 | 生成完成后自动滚到结果，提供 `保存` + `在 Finder 中显示` |
| 清空 | 两步确认；**清空必须回到完全初始态**（输入框、模式、选区、产物列表、文稿记录全部复位） |
| 切走再回来 | 恢复任务与选区（localStorage + 服务端任务索引） |
| 失败 | 错误条 + 一个可执行动作（重试 / 登录 / 换模式），不出现裸报错 |

## 八、空状态 / 加载 / 错误

### 8.1 空状态

| 位置 | 文案方向 | 视觉 |
|---|---|---|
| 未解析 | 「贴一条链接开始」+ 支持站点示例 | 图标 + 一行说明 + 灰底输入框 |
| 已解析未下载 | 显示封面与元信息，下载按钮高亮 | 缩略图 + 信息 |
| 已下载未提文案 | 「有字幕会直接抓，没有就用本地 whisper」 | 一行引导 |
| 无剪辑/无 GIF | 「定好起止点，点一下就存」 | 虚线框 |
| 拼接队列为空 | 「攒几段再导出」 | 虚线框 |
| 历史为空 | 「还没有任务」+ 引导 | 图标 |
| 工具缺失 | 「缺 ffmpeg，点此查看安装命令」 | 黄色警示条 |

### 8.2 加载状态

| 动作 | 形态 | 说明 |
|---|---|---|
| 解析 | 骨架屏（缩略图 + 两行文字） | <300ms 不显示，避免闪烁 |
| 下载 | 进度条 + 百分比 + 速度 + ETA + 取消 | 未知总大小时用不定长流动条 |
| 转写 | 阶段文字（找字幕 / 抽音轨 / 转写中）+ 计时 | 长任务显示已用时 |
| GIF | 档位进度（第 2/8 档，480px/10fps） | 让用户知道“在压缩” |
| 试播切片 | 按钮内 loading | 首次 0.3–0.5s |
| 导出 | 按钮 loading | 完成后 toast + 路径 |

### 8.3 错误状态
- 一律「一句人话 + 一个动作」：`这个链接需要登录` →【用浏览器抓正文】；`站点不支持` →【改用文稿模式】；`ffmpeg 失败` →【重试】+ 查看日志。
- 禁止把子进程原始 stderr 直接贴给用户。

## 九、任务状态模型

```
idle → parsing → parsed → downloading → downloaded
                                 ↓
                       transcribing → transcribed
                                 ↓
                       clipping / gif / merge → done
任意阶段 → error（保留已完成部分）
```

- 每个任务有唯一 id，产物（mp4/GIF/合并）挂在任务下；
- 任务索引持久化到磁盘，重启可恢复；
- 同一 URL 复用任务，不重复下载。

## 十二、验收标准

1. 贴一条 B 站链接到拿到 ≤5MB 的 GIF，全程 ≤5 次点击，无页面跳转。
2. 清空后，面板回到完全初始态（含模式），刷新仍是初始态。
3. 任何模式下，卡片编号从 ① 连续递增，无跳号。
4. 所有异步动作都有可见进度；所有失败都有可执行的自救动作。
5. 深浅色主题下均无硬编码颜色、无对比度不足的文字。
6. 切到对话再切回、重启 DSH 后，任务与选区仍在。
